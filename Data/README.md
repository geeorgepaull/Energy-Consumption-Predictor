# Data Files

Download both datasets and place them in this folder before running the notebooks.

| File | Source |
|------|--------|
| `household_power_consumption.txt` | [UCI Individual Household Electric Power Consumption](https://archive.ics.uci.edu/dataset/235/individual+household+electric+power+consumption) |
| `Steel_industry_data.csv` | [UCI Steel Industry Energy Consumption](https://archive.ics.uci.edu/dataset/851/steel+industry+energy+consumption) |

Use the exact filenames shown above so the notebooks can load them automatically.
